💼 1. BUSINESS (ផែនការអាជីវកម្ម)

1.1 Executive Summary (សេចក្តីសង្ខេបអាជីវកម្ម)

TechTonic Store (Electronic Store) គឺជាវេទិកាពាណិជ្ជកម្មអេឡិចត្រូនិក B2C E-Commerce ជំនាន់ថ្មី ដែលផ្គត់ផ្គង់ឧបករណ៍អេឡិចត្រូនិកទំនើបៗ (Modern Consumer Electronics) ដូចជា ឧបករណ៍សម្លេងកម្រិតស្ទូឌីយោ, នាឡិកាវៃឆ្លាត Smart Wearables, គ្រឿង Ergonomic Desk Setups, និង Fast Power Accessories ក្នុងប្រទេសកម្ពុជា។

Software Engineers

ក្ដារចុច 75% Mechanical Tactile, Vertical Mice និងកាស ANC ការពារសម្លេងរំខាន។

University Students

2.1 Modern Technology Stack (បច្ចេកវិទ្យាប្រើប្រាស់)

Layer Technology តួនាទី & អត្ថប្រយោជន៍ (Role & Justification)

State Management React Context + LocalStorage គ្រប់គ្រង Cart State, Wishlist និង Auth ដោយរក្សាទុក Persistence មិនបាត់ពេល Refresh
Vector Icons Lucide React Clean SVG Vector Icons ស្ដង់ដារសកល គ្មាន Emoji ជួយឱ្យ UI មើលទៅ Professional

2.2 Core System Modules & Delivery Integration

🛍️ 1. Storefront & Multi-Variant Catalog

ទំនិញ ៤០ មុខ ជាមួយការជ្រើសរើសពណ៌ Switch ភ្លាមៗ, Search keyword, Category filter និង Brand loop។

🚚 2. Cambodia Delivery Logistics Integration

ភ្ជាប់ប្រព័ន្ធដឹកជញ្ជូនឈានមុខនៅកម្ពុជា Vireak Buntham Express (VET) (គ្រប់ ២៥ ខេត្ត-ក្រុង) និង J&T Express Cambodia (Door-to-Door Express) ជាមួយ Barcode Tracking។

📍 3. Real-Time Order Tracking Telemetry

តាមដានដំណើរការដឹកជញ្ជូន ៥ ដំណាក់កាល (`Confirmed` → `Delivered`) ជាមួយលេខ Tracking និងតំណភ្ជាប់ផ្លូវការទៅកាន់ក្រុមហ៊ុនដឹកជញ្ជូន។

🗄️ 3. DATABASE DESIGN (ការរចនាទិន្នន័យ & ERD)

3.1 Complete Data Dictionary (តារាងទិន្នន័យទាំង ៨)

Table Name Primary Key Foreign Key (FK) Reference Data Types Used ការពិពណ៌នា (Description)
users id - UUID, VARCHAR ព័ត៌មានគណនីអតិថិជន និង Admin (`customer`, `admin`)
user_addresses id user_id → users.id UUID, VARCHAR អាសយដ្ឋានដឹកជញ្ជូនច្រើនកន្លែងរបស់អតិថិជន
categories id - VARCHAR, INT ប្រភេទផលិតផល (Audio, Wearables, Keyboards, Power)
products id category_id → categories.id VARCHAR, NUM, JSON ព័ត៌មានលម្អិតនៃទំនិញ (តម្លៃ, ស្តុក, ជម្រើសពណ៌, Specs)
orders id user_id → users.id VARCHAR, NUM, JSON ការបញ្ជាទិញ, ព័ត៌មានដឹកជញ្ជូន (VET / J&T Express), tracking_number, និងស្ថានភាពទូទាត់ប្រាក់
order_items id order_id → orders.id
product_id → products.id 		UUID, NUM, INT Junction Table: បំបែក Many-to-Many រវាង Orders & Products
product_reviews id product_id → products.id
user_id → users.id 		UUID, INT, TEXT ការវាយតម្លៃផ្កាយ (1-5 Stars) និងមតិយោបល់របស់អតិថិជន
promo_codes code - VARCHAR, NUM គូប៉ុងបញ្ចុះតម្លៃសម្រាប់ Checkout (ឧ. `WELCOME10`)

3.2 Relationships Matrix

Relationship Cardinality FK Binding ការពន្យល់បច្ចេកទេស
users → user_addresses 1 : N user_addresses.user_id User ម្នាក់អាចមានអាសយដ្ឋានដឹកជញ្ជូនច្រើន (Home, Work)
categories → products 1 : N products.category_id Category មួយមានទំនិញជាច្រើនមុខ
users → orders 1 : N orders.user_id User ម្នាក់អាចបញ្ជាទិញបានច្រើនដងតាមពេលវេលាផ្សេងគ្នា
orders ↔ products N : N via order_items Order ម្តងមានទំនិញច្រើន ហើយទំនិញមួយមានក្នុង Order ច្រើន (Junction Table)
products → product_reviews 1 : N product_reviews.product_id ទំនិញមួយមុខអាចមាន Review ផ្កាយច្រើនពីអតិថិជន
